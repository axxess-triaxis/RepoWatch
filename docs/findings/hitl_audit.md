## Three cross-cutting findings

1. **Every HITL signal is AI-mediated, not independently verifiable.** All
   5 "human-reviewed decision" classifications rest on
   `Co-Authored-By: Claude Sonnet 5` commit bodies that attribute decisions
   to the founder. The only unambiguously verifiable human action in this
   window is the App Store Connect submission in #365. All others are the
   AI's written account of what the founder decided — no PR review thread,
   no approval comment, no visible back-and-forth in the git record. The
   attributions are specific enough (submission IDs, exact protocol steps,
   named rejections) that fabrication is unlikely, but **they cannot be
   independently confirmed from the repository alone.** This is arguably
   the sharpest finding of the whole audit: a tool built to catch AI
   decisions rubber-stamped without HITL has to acknowledge that even its
   own "HITL confirmed" verdicts are reading the AI's own account of what
   happened, not an independent record.
2. **The one concrete gap is #359** — a major-version native dependency
   bump merged without any recorded human assessment, unlike every other
   (patch/minor) Dependabot PR in the window.
3. **The sample is too narrow to generalize.** All 5 human-authored PRs
   come from a single incident sequence (iOS icon → darwin fix → two ledger
   closeouts → Android closeout). None involve a security decision, a
   schema migration, a new feature, or an architecture call — a window
   including those would test the HITL model substantially harder.
